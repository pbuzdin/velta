Velta Dash

If a Velta contact sent you a file and you opened it in Delta Chat or ArcaneChat, this page is for you. The message you saw is a Velta Dash offer. The file is not sitting in the email — it is waiting to travel directly from their app to yours.

What Velta Dash is

Velta Dash sends files of up to 2 GB straight from one Velta app to another, over an encrypted connection, instead of attaching them to an email. In a one-to-one chat between two Velta users, files over 6 MB, up to 2 GB, go this way automatically, including files too big for email.

Both apps need to be able to connect: usually while both people have Velta open and online. A short encrypted message carries the offer; the file itself then moves device to device.

How to get the file

Delta Chat and other chatmail apps can show the offer, but they cannot complete a Dash transfer. To receive the file, install Velta — the Android or desktop app — and open the same chat with the same account you already use. While the sender is reachable, Velta fetches the file directly. The browser app cannot receive a Dash transfer.

Is it private?

Yes. The offer arrives in an end-to-end encrypted message, like any other Velta or Delta Chat message. The file itself travels over an encrypted connection between the two devices. A relay may help the apps find each other when a direct path is not available, but it cannot read the file.

If the file does not arrive

If Velta cannot complete the transfer — for example if the sender is offline — it can fall back to sending the file as a normal email attachment, up to the email size limit of 22 MB. Files over 22 MB can only travel with Dash, up to the 2 GB limit, so both sides need to be on Velta and able to connect. If an offer has already expired, ask the sender to share the file again.
