Velta 1.5.6: a composer with a tools row, a catalog at home, and old Macs launch again

21 November 2026 · 3 min read

The composer gets a permanent tools row on desktop and an armed send everywhere, the app catalog gains a Velta-hosted mirror, and the 1.5.5 launch failure on older macOS is fixed. Plus Profiles in the drawer, toggles for the new composer tools, and 49 more strings in French and Russian.

1.5.6 is a reach release: almost everything in it shortens the distance between "I want to do this" and the thing happening. The composer learns where its tools live, the app catalog gets a mirror we host ourselves, and one quiet fix lets 1.5.5's forgotten users — people on older Macs — finally open the app at all.

The composer grows up

Since 1.5.5, typing expands the message field to a full-width column with the buttons on a row below. On the phone that behavior is unchanged. On desktop it no longer waits for the first keystroke: the two-row layout is now permanent, so the send button lives in one place from the moment a chat opens — it stops jumping between "inline at rest" and "below while typing" every time you clear the field.

Send also learned to show its state. While there is text in the field it fills with the accent color; when the field is empty it goes back to the quiet outline arrow. One glance tells you whether the message is armed.

Tools within reach

That desktop tools row now carries more than paperclip and send. Apps and Commands sit beside the attach button — your recent webxdc apps and recent slash commands, one tap each, with Send later next to send. All three wear text captions, and Commands wears a new keycap-slash icon. Each of them still lives in the attach menu too, and phones keep everything in that menu, where there is room.

Two of them can be switched off if you never use them — under Chat appearance, "Send later" turns the whole scheduling feature off (every entry point, including the keyboard shortcut), and "Commands button" hides the quick tool. Both apply without a reload.

The catalog has a mirror at home

The in-app app catalog has always listed a public mirror; now it tries three, in order: the upstream catalog, velta.cc/apps — a static mirror we host ourselves, synced from upstream — and a community mirror as the last fallback. The client remembers which one answered and starts there next time. Our mirror curates: one catalog app was left out of it. The catalog screen also got its spacing fixed, and the Add-mirror button finally matches the height of the field it sits beside.

Old Macs launch again

1.5.5 had a bug that mattered more than its size: on macOS versions whose system WebKit predates Safari 17.2, the app failed to start at all — a single line of new JavaScript syntax killed the whole program before the first screen drew, and the only visible sign was a syntax error mentioning a keyword called with. Windows and Android never noticed. 1.5.6 loads its translations in a way every engine understands, and the app opens. If 1.5.5 never launched on your Mac, this release is the one to install.

Profiles, and a header that knows you

The drawer's account switcher now says Profiles — the word the rest of the app already used. And the drawer header takes its color from the profile you are in: a gradient built from the profile's identity color, rotated per profile and checked against the text on top of it for every hue it can produce, so switching profiles changes the header without ever hurting readability.

Also in this release

  • Slash suggestions keep their manners — sending "/coverage run 42" no longer suggests the whole line back; only the bare command is remembered, and the arguments stay yours to type.
  • The attach menu scrolls properly — opening the Apps or Commands sections no longer spills content past the menu's edge; the menu owns one scrollbar and stays inside the window.
  • 49 more strings translated — the lock screen, backup and transfer errors, server errors from large-file uploads, call refusals, and the in-app browser are all in French and Russian now; the two languages still cover the whole interface.
