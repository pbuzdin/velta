Velta 1.5 encrypts attachments and replaces the DNS tunnel

2 November 2026 · 4 min read

Attachments are encrypted on disk, mail can ride a SOCKS5 proxy instead of the old DNS tunnel, you can pause a relay without deleting it, and the app-lock PIN also unlocks the auto-lock screen.

This note gathers what changed since 1.4.89. Profile databases were already encrypted on Android. 1.5 finishes the on-device picture, retires the DNS tunnel, and makes relays and the lock screen easier to live with.

Attachments encrypted on disk

Pictures, videos and files in a chat are now encrypted on the device, the same way the message database already is on Android. Opening a backup still works in Delta Chat: the export is the usual unencrypted archive. Until this landing, attachments relied on the phone’s own isolation; 1.4.89 said so. That work is done.

SOCKS5 instead of the DNS tunnel

The DNS tunnel is gone. Native apps (Android, Windows, macOS) can send mail through a SOCKS5 proxy you save on this device, your LAN, or the internet, with an optional username and password. Share one as a velta://proxy link, a QR code, or a card in chat — Velta names the server and warns about credentials before it is added. A WebSocket proxy still works; pick one or the other.

Pause a relay

In the Relays list you can Disable a relay without deleting it. Sends skip it immediately; fetch skips it at the next reconnect. Mail already stored there stays. Pausing every relay takes the profile offline on purpose.

Add relays automatically is now a switch in that same list, off by default. Older profiles that had it on are flipped off once at upgrade.

The PIN also unlocks auto-lock

With a fingerprint and a Velta PIN both on, cancelling the biometric prompt used to leave no way in short of killing the app. The auto-lock screen now offers Use PIN as well: it checks the PIN there and then, with the same growing waits after wrong tries as at start, and it never drops the lock without a match.

A log you turn on

File logging is off unless you turn it on in About Velta or Velta Diagnostics. When you need a log, About can copy or share the last stretch of it. A few startup heartbeats still write, so a stuck splash has a trail.

Push that says when it failed

On Android, Settings → Push notifications now shows when the push app could not register, with the reason it gave. Pick another distributor, or turn push off, from the same screen.

Steadier chats

Opening or switching chats could hang for half a minute, especially with a saved proxy whose server was unreachable. That freeze is gone: mail connections no longer block the chat, and coming back to the app no longer waits on a fetch started while it was hidden.

The message menu stays on the bubble and in the viewport. A contact’s profile lists every relay address, primary first.
