Velta 1.4.88 adds admin groups

29 October 2026 · 2 min read

Groups can have one admin who controls members, settings and pins, profile keys show up correctly again, and threaded bubbles no longer shrink to one letter wide.

A small release with one big switch. It follows 1.4.87 by a day.

Admin groups

Turn on Admin group in the New group dialog and you become the group’s only admin. Only you can add or remove members, change the name, description, avatar, disappearing-message timer and pins, and you can delete any message for everyone. The group’s info sheet says Moderated group · admin: you with an Admin badge, and the admin’s messages carry a small Admin chip.

The rules are not just hidden buttons: the other members’ apps enforce them too. Admin groups work with ArcaneChat’s admin groups, so mixed groups behave the same on both apps.

Fixed

  • Profile keys showing “-”. The October messaging engine changed how it reports encryption details; Velta reads them correctly again, so avatars and profile keys show the real key.
  • One-letter-wide bubbles. A threaded message that shared its row with the unread line no longer collapses into one letter per line.
