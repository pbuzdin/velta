Send directly is now Velta Beam

15 October 2026 · 3 min read

Peer-to-peer file transfer sits just under the chat header, with a progress line for every receiver.

In 1.4.72 the direct file transfer stopped being a buried command and took a name. Velta Beam opens as a panel under the chat header. You can keep reading and writing while a file moves. Expand it to the full screen, or close it.

The sender sees every receiver: how many there are, a percent for each, and done when that receiver’s checksum matches. It works in a group, not only in a one-to-one chat.

The same release fixes the Android path. The built-in transfer had been going out as plain text, so opening it said the app was not found. It is now sent as a real webxdc mini-app.

What Beam is not

Beam is not a second account and not a public file host. The bytes go to the people already in the chat. A relay is the long way around. Beam is the straight line.
