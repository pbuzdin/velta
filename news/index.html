News

Release notes, guides, and engineering notes. No mailing list.

  • Velta 1.5.7: Loop transfers that finish, a composer in one row, and a Dash that explains itself →

    27 November 2026 · Release

    Two-way Loop transfers no longer freeze at 99%, the desktop composer collapses to a single armed row, and the Dash card explains itself to Delta Chat users — and stops showing ghost copies after a profile is remade. Plus image Copy/Save in the message menu, the sealed-vCard import fix, a folder size pre-flight, and a keychain scoped per identity.

  • We profiled Velta's web layer for the 5% worth rewriting →

    23 November 2026 · Engineering

    We ran the fast-anything experiment on Velta: profile the JavaScript layer, port the hot functions to Rust, verify they behave identically. Markdown renders in 0.36 ms, a paging port came out 177× slower across the language boundary, and a verified 4.5× CRC rewrite taught us the win was the algorithm, not the language.

  • Velta 1.5.6: a composer with a tools row, a catalog at home, and old Macs launch again →

    21 November 2026 · Release

    The composer gets a permanent tools row on desktop and an armed send everywhere, the app catalog gains a Velta-hosted mirror, and the 1.5.5 launch failure on older macOS is fixed. Plus Profiles in the drawer, toggles for the new composer tools, and 49 more strings in French and Russian.

  • Why Velta changes the chatmail core and relay →

    18 November 2026 · Engineering

    We vendor the chatmail core and keep a public fork of the relay, with a short, documented set of changes on top of both. Here is why. The living lists stay on GitHub.

  • Our Rust UI take: what two days of native Velta taught us →

    12 November 2026 · Engineering

    We built a working Velta client for Android in Rust — no WebView, no browser engine — and ran it on a mid-range phone next to the web app. What the experiment proved, where the costs came due, and why our Android effort went back into the Kotlin client, with the same core in-process.

  • Velta 1.5.5: a glass composer, background sends, and Linux packages that are really there →

    10 November 2026 · Release

    The message field can turn to glass on Windows and Android, a backgrounded send shows a silent notification until it lands, and the Linux packages are finally on the release page. Plus voice playback speed, category chips in the pickers, and messaging core 2.69.0.

  • Velta 1.5.4: Windows Hello that works, Text-only mode, and Linux packages →

    7 November 2026 · Release

    Windows Hello works end to end and its prompt comes to the front on its own. Text-only mode covers unknown senders by default, relay failover is visible, and attachment encryption is out of preview.

  • Velta 1.5.3 adds pure black, opens documents in your default app, and lets the chat list step aside →

    A pure-black AMOLED option for the dark theme, stickers in the attachments menu, documents that open in your default app, and a chat list you can collapse on wide windows.

    5 November 2026 · Release

  • Velta 1.5.2: Windows Hello and an end to large-chat freezes →

    3 November 2026 · Release

    Windows desktop can unlock the database key with Windows Hello. Opening a large chat no longer fills the database and freezes the app, and Restart core no longer stacks.

  • Velta 1.5.1: a watchdog for the core, steadier lists →

    3 November 2026 · Release

    When the core stalls, the Relays screen and chat list keep their last good state behind a Retry banner, a watchdog restarts a stuck core, and transfers, search and first sync finally show progress.

  • Velta 1.5 encrypts attachments and replaces the DNS tunnel →

    2 November 2026 · Release

    Attachments are encrypted on disk, mail can ride a SOCKS5 proxy instead of the old DNS tunnel, you can pause a relay without deleting it, and the app-lock PIN also unlocks the auto-lock screen.

  • Velta 1.4.89 encrypts profile data on Android →

    31 October 2026 · Release

    Profile data is now encrypted at rest on Android (preview on desktop and in the browser), a new Privacy & security screen holds the app lock, and Android gets a biometric lock with a PIN fallback.

  • Velta 1.4.88 adds admin groups →

    29 October 2026 · Release

    Groups can have one admin who controls members, settings and pins, profile keys show up correctly again, and threaded bubbles no longer shrink to one letter wide.
