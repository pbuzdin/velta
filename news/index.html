News

Release notes and one guide to how a message moves. No mailing list.

  • Velta 1.5.3 adds pure black, opens documents in your default app, and lets the chat list step aside →

    A pure-black AMOLED option for the dark theme, stickers in the attachments menu, documents that open in your default app, and a chat list you can collapse on wide windows.

    5 November 2026 · Release

  • Velta 1.5.2: Windows Hello and an end to large-chat freezes →

    3 November 2026 · Release

    Windows desktop can unlock the database key with Windows Hello. Opening a large chat no longer fills the database and freezes the app, and Restart core no longer stacks.

  • Velta 1.5.1: a watchdog for the core, steadier lists →

    3 November 2026 · Release

    When the core stalls, the Relays screen and chat list keep their last good state behind a Retry banner, a watchdog restarts a stuck core, and transfers, search and first sync finally show progress.

  • Velta 1.5 encrypts attachments and replaces the DNS tunnel →

    2 November 2026 · Release

    Attachments are encrypted on disk, mail can ride a SOCKS5 proxy instead of the old DNS tunnel, you can pause a relay without deleting it, and the app-lock PIN also unlocks the auto-lock screen.

  • Velta 1.4.89 encrypts profile data on Android →

    31 October 2026 · Release

    Profile data is now encrypted at rest on Android (preview on desktop and in the browser), a new Privacy & security screen holds the app lock, and Android gets a biometric lock with a PIN fallback.

  • Velta 1.4.88 adds admin groups →

    29 October 2026 · Release

    Groups can have one admin who controls members, settings and pins, profile keys show up correctly again, and threaded bubbles no longer shrink to one letter wide.

  • Velta 1.4.87: invites on velta.cc, steadier Android, a new message menu →

    29 October 2026 · Release

    Four releases in one: invite links that live on velta.cc, an end to the minutes-long chat stalls on Android, images that always appear, Cryptex as a second large-file provider, Chatmail core 2.66.0, and a reworked message menu.

  • Velta 1.4.83 is faster and adds Send later →

    26 October 2026 · Release

    The app is quicker on busy accounts, messages can be scheduled, mail can travel over a WebSocket proxy with invite links, and Android delivers more reliably in the background.

  • Velta 1.4.82 adds French, Russian, and an app catalog →

    25 October 2026 · Release

    The interface can be French or Russian, the attach menu browses mini-apps, and opening someone’s profile no longer stalls on a large account.

  • Velta 1.4.79 brings Velta Beam to groups →

    23 October 2026 · Release

    Velta Beam works in group chats now, the Accounts menu hosts Profile management, and a person’s profile no longer lists everyone’s files.
