Release notes and one guide to how a message moves. No mailing list.

  • Velta 1.4.89 encrypts your messages on the device →

    Message databases are now encrypted at rest on every platform, a new Privacy & security screen holds the app lock, and Android gets a biometric lock with a PIN fallback.

    31 October 2026 · Release

  • Velta 1.4.88 adds admin groups →

    Groups can have one admin who controls members, settings and pins, profile keys show up correctly again, and threaded bubbles no longer shrink to one letter wide.

    29 October 2026 · Release

  • Velta 1.4.87: invites on velta.cc, steadier Android, a new message menu →

    Four releases in one: invite links that live on velta.cc, an end to the minutes-long chat stalls on Android, images that always appear, Cryptex as a second large-file provider, Chatmail core 2.66.0, and a reworked message menu.

    29 October 2026 · Release

  • Velta 1.4.83 is faster and adds Send later →

    The app is quicker on busy accounts, messages can be scheduled, mail can travel over a WebSocket proxy with invite links, and Android delivers more reliably in the background.

    26 October 2026 · Release

  • Velta 1.4.82 adds French, Russian, and an app catalog →

    The interface can be French or Russian, the attach menu browses mini-apps, and opening someone’s profile no longer stalls on a large account.

    25 October 2026 · Release

  • Velta 1.4.79 brings Velta Beam to groups →

    Velta Beam works in group chats now, the Accounts menu hosts Profile management, and a person’s profile no longer lists everyone’s files.

    23 October 2026 · Release

  • Velta 1.4.78 adds reply threads and @mentions →

    Replies collect into threads, @mentions survive renames, the chat list gains an Unread chip, and muted chats stay quiet everywhere.

    23 October 2026 · Release

  • A CMS made of four git calls →

    The tool that edits velta.cc is one page and four JSON operations against git. Its contract now has a home at velta.cc/cms.

  • The design system, published →

    The token reference behind Velta's look now has a home at velta.cc/design.

  • Velta 1.4.74 closes a local door →
