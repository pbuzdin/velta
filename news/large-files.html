Large files leave as an encrypted link

15 October 2026 · 3 min read

On desktop, a large attachment is encrypted on your device, uploaded through your proxy, and posted as a link anyone can open.

Version 1.4.70 adds Attach → Large file on desktop. Velta encrypts the file before it goes anywhere, uploads it to a Lufi server — upload.disroot.org, unless you change it — through the proxy you already use, and posts the link in the chat.

Someone without Velta can open that link in a browser. Expiry, burn after reading, and delete-from-server are part of the same flow.

This is the path for a file that is too clumsy to attach directly. It is not Velta Beam. A Lufi link does sit on a server you choose. Beam does not.
