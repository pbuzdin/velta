Velta 1.5.2: Windows Hello and an end to large-chat freezes

3 November 2026 · 3 min read

Windows desktop can unlock the database key with Windows Hello. Opening a large chat no longer fills the database and freezes the app, and Restart core no longer stacks.

Two things that made the app feel stuck are in this release: a large chat that froze everything, and a Windows machine that kept the database key in Credential Manager with no way to ask for you at startup.

Windows Hello

On Windows, Privacy & security can hand the database key to Windows Hello. A PIN, face, or fingerprint unwraps it. Turning Hello on removes the copy that lived in Credential Manager, and a cold start stays locked until Hello succeeds. The app-lock PIN can stay beside it — either one unlocks, and turning the last one off puts the key back in Credential Manager.

The button is hidden when this Windows account has no Hello set up, which is common on a remote desktop or some virtual machines. Android's biometric lock is unchanged.

Large chats

Opening a large chat could freeze the whole app. The "N replies" count joined the message table to itself and scanned the chat twice, and every open started another copy. Three of those filled the database, so opening another chat and restarting mail both waited behind them. 1.5.2 looks the quoted message up by its id, and the chat view runs only one of those counts at a time.

If the app is already frozen on an older build, install this one and quit that process. A build that is already inside the old query does not pick up the new one until it exits.

Restart core

Restart core no longer stacks on itself. Stopping mail connections gives up after 15 seconds and starts them again anyway. A database statement that has already started still runs to the end — that is the same reason a process already stuck on an older build has to be quit.

A quieter watchdog

The core watchdog no longer treats a backup, a relay add, or a call as a stall. Those calls are slow on purpose. If the clock jumps — the laptop slept, the phone froze — the app treats that as coming back, not as every call being minutes old. A call that timed out and never answered stops counting after two minutes.

On Android the banner sits below the status bar, so it is not drawn under the clock.

Also in this release

  • Keyboard focus in the light theme uses a darker blue ring, so the outline stays readable on a white surface. Text selection uses its own color instead of the pressed-row color.
