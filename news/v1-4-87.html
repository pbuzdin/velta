Velta 1.4.87: invites on velta.cc, steadier Android, a new message menu

29 October 2026 · 4 min read

Four releases in one: invite links that live on velta.cc, an end to the minutes-long chat stalls on Android, images that always appear, Cryptex as a second large-file provider, Chatmail core 2.66.0, and a reworked message menu.

Versions 1.4.84 through 1.4.87 arrived in quick steps; this note gathers what changed since 1.4.83. The through-line: things that used to get stuck — a chat that would not open, an image that would not appear — now fix themselves.

Invites live on velta.cc

When you share an invite, the link now points to velta.cc/join. Open it in a browser and you get a page that says who invited you, offers a button that opens the chat straight in the app, and shows the QR for moving the chat to another device. No account, no tracking — the invitation is just the link. Links in the older Delta Chat format keep working everywhere, including pasted ones.

The end of the minutes-long stalls

On Android, after a network change the app sometimes froze for a few minutes: chats would not open, the list stopped updating, categories came up empty. The cause sat deep in the messaging engine — a reconnect held a lock while old connections wound down, and everything else queued behind it. Two fixes landed across 1.4.85 and 1.4.87, and the queue is gone: switching chats after a send works, and a background reconnect can no longer hold the interface hostage.

Images that always appear

A picture in a chat could occasionally stay an empty box for the rest of the session — the image had loaded, but the moment of its arrival was missed. Rows now heal themselves when you come back to them. No restart, no forwarding the message to another chat to see it.

Cryptex: a second home for large files

Big attachments travel through a file host. Cryptex joins Lufi as a second provider, so a large file gets a fallback when its first host is unreachable.

A calmer message menu

The message menu is now a three-column grid in the style of Firefox’s menus, delete confirms inline instead of a dialog, the emoji picker opens full height, and the sheet’s drag handle is easier to grab.

Chatmail core 2.66.0

Under the hood the messaging engine moved to the October upstream release: marking messages seen and queueing read receipts happen in one transaction, and the IMAP loop skips full table scans. All of Velta’s engine patches carried over unchanged — the release builds compile the patched core.

Also in these releases

  • Import a backup into a new profile from Profile management; the profile you use stays signed in.
  • Bots and People in the chat list re-check their categories every time you pick the chip, per account.
  • Editing a message no longer counts as a reply to it in reply counts and the thread panel.
  • The DNS tunnel’s Off switch really turns the tunnel off now, and the drawer row is there before any tunnel is saved.
  • The invite QR carries the Velta logo, stays square, is shareable, and has pills to pick the invite domain.
  • Relay details no longer stack over the Add relay button; opening a normal chat hides the diagnostics actions.
  • In the browser, the update notice stays until you reload, and controls that only make sense in the apps are hidden.
  • Android’s background check-in gives up sooner, never runs while you are using the app, and no longer drops a restart halfway.
