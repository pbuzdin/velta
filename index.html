Delta Chat client

Private messages. No company in the middle.

Velta is encrypted chat on the email network. Messages travel through chatmail relays you choose, or go straight across with Velta Beam. One interface on Android, Windows, macOS, and in the browser. No analytics.

Product

The app is the client. The network is not ours.

Velta does not run a messaging server and does not sell the directory. You bring a chatmail address. The app is the client.

Messages go by relay

Chat travels as encrypted mail through chatmail relays you choose. Keep more than one, mark one as primary, fail over when it drops. The relay stores ciphertext and sees timing and size — never the words.

Files go direct with Beam

Velta Beam moves a file peer to peer to the people already in the chat — a progress line for every receiver until the checksum matches. No relay in between, and no extra copy sitting on a server.

Features

What the client actually does

Read the longer note

  • Encrypted on the device

    OpenPGP, handled by the Delta Chat core. Velta has no master key and does not keep yours.

  • Relays you pick

    More than one chatmail relay on a profile. One is primary for sending. Another takes over if it drops.

  • Velta Beam

    A file goes peer to peer to the people in the chat. You see each receiver until the checksum matches.

  • Local chat

    Beta. A serverless room on the same network, over iroh QUIC. Up to five devices. 256 MB in a pair, 32 MB in a group.

  • Audio calls

    Beta, and one to one. Set up through the encrypted chat. The ring only sounds while the app is open.

  • Profiles you can leave with

    Add, export, transfer, delete. The identity is an email address, not a phone number and not an account with us.

  • Quiet by default

    Disappearing messages, tracking parameters stripped from links, HTML mail drawn in a sandboxed frame.

  • The daily tools

    Full-history search, pins that sync, edits to your own text, and ticks for sent, delivered, and read.

Privacy

Nothing phones home.

The promises below are properties of the build, not a policy you have to trust a dashboard to enforce. The source is public.

View the source

  1. 01

    No telemetry

    No analytics, no crash reports, no account of yours on a Velta server.

  2. 02

    Your mailbox, not ours

    Chatmail relays hold ciphertext. Velta does not operate them and cannot read the mail.

  3. 03

    The app loads itself

    A strict content security policy. Pages inside a message do not share the app’s origin.

  4. 04

    Links stay clean

    Previews can be off, sent as a picture, or loaded on the device. Tracking parameters are stripped.

  5. 05

    Tunnel is opt-in

    Android can use a DNS tunnel on a blocked network. It stays off until you enable it.

  6. 06

    You can leave

    Export the profile. Delete it. The license is GPL-3.0, so the client can be forked.

Platforms

One web interface. Four shells.

Windows, macOS, and Android wrap the same frontend with Tauri. The browser build is that frontend with a WebAssembly core. You are not learning a different app on each desk.

Android

49 MB · arm64

  • Needs an arm64 phone.
  • The chat core runs inside the app, with a foreground service so sync continues after you leave.
  • Optional DNS tunnel when a network blocks mail. Off until you turn it on.

Windows

13 MB · x64

  • x64 installer. The core ships beside the app.
  • One-click updates when a newer build is published.
  • Invite links can open through the velta:// scheme.

Download installer

macOS

36 MB · universal test build

  • Apple Silicon and Intel, macOS 10.15 or newer.
  • Ad-hoc signed, not notarized. The first open needs an extra approval.
  • One-click updates, same as Windows.
First launch on macOS

Drag Velta into Applications. Then clear quarantine once in Terminal: xattr -dr com.apple.quarantine /Applications/Velta.app. Or open it, fail once, and choose Open Anyway under System Settings → Privacy & Security.

Download DMG

Browser

Self-hosted PWA

  • The same interface, with the core compiled to WebAssembly.
  • You host the static site. Mail goes out through a relay’s WebSocket proxy.
  • A refresh keeps the signed-in profile. A crash can drop the last few seconds.
