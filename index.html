Private messages.

Velta is a Delta Chat client: encrypted chat, with no company in the middle. Messages travel through chatmail relays you choose, or go straight across with Velta Beam. One interface on Android, Windows, macOS, and in the browser. No analytics.

The ring and the chord.

Velta does not run a messaging server and does not sell the directory. You bring a chatmail address, and the app is the client. Most messages take the ring: encrypted mail through relays you choose. Files take the chord: straight across. Choose a route below and see what each one means.

The ring

hey! did you see the new chatmail relay release?

08:49

The ring. Chat travels as encrypted mail through chatmail relays you choose. Keep more than one, mark one as primary, fail over when it drops. The relay stores ciphertext and sees timing and size, never the words. Plain email is dropped on arrival, so there is no spam either.

Built on Delta Chat.

Read the longer note

Encrypted end to end

OpenPGP, handled by the Delta Chat core, the client the protocol comes from. Velta has no master key and does not keep yours.

Reactions, threads, mentions

React to any message, reply in threads with reply counts, and @mention someone in a way that cuts through mutes.

The everyday tools

Full-history search, pins that sync, edits to your own text, read ticks, and messages scheduled with Send later for the exact minute they should land.

Apps in a message

Small web apps run inside the chat as a card. Their pages are drawn in a sandboxed frame that does not share the app’s origin.

What Velta adds.

  • Velta Beam

    A file goes peer to peer to the people in the chat; you see each receiver until the checksum matches.

    no relay in between

  • Velta Loop

    A serverless local room on the same network, over iroh QUIC. Up to five devices.

    beta · 256 MB in a pair

  • Relays you pick

    More than one chatmail relay on a profile; one is primary, another takes over if it drops. Signed invite links bring someone in through /join.

    failover included

  • Velta Prism

    Every person gets their own color, everywhere: chats, groups, calls. Recognize who is who without photos.

    one color per person

  • Velta Circle

    Group audio calls for up to six people, set up through the encrypted chat. The ring only sounds while the app is open.

    six on a call

  • Locked when you walk away

    The database and attachments are encrypted at rest. A PIN or your fingerprint locks the app; identity backups stay end-to-end encrypted.

    encrypted at rest

  • Quiet by default

    Disappearing messages, tracking parameters stripped from links, HTML mail drawn in a sandboxed frame.

    trackers stripped

  • Profiles you can leave with

    Add, export, transfer, delete. The identity is an email address. The same address chats with anyone on the official Delta Chat apps, and moves in or out of Velta at any time.

    export any time

  1. Nothing phones home.

    The promises below are properties of the build, not a policy you have to trust a dashboard to enforce. The source is public, and the frontend ships as plain ES modules: no build pipeline between what you read and what your browser runs.

    View the source

  2. No telemetry

    No analytics, no crash reports, no account of yours on a Velta server.

  3. Your mailbox, not ours

    Chatmail relays hold ciphertext. Velta does not operate them and cannot read the mail.

  4. The app loads itself

    A strict content security policy. Pages inside a message do not share the app’s origin.

  5. Links stay clean

    Previews can be off, sent as a picture, or loaded on the device. Tracking parameters are stripped.

  6. Tunnel is opt-in

    Android can use a DNS tunnel on a blocked network. It stays off until you enable it.

  7. You can leave

    Export the profile. Delete it. The license is GPL-3.0, so the client can be forked.

This website measures its own visits cookielessly, in aggregate. The app has no telemetry and never phones home.

First launch on macOS

Drag Velta into Applications. Then clear quarantine once in Terminal: xattr -dr com.apple.quarantine /Applications/Velta.app. Or open it, fail once, and choose Open Anyway under System Settings → Privacy & Security.

    How can you help Velta

    No company is behind this app, so every kind of help is the good kind. Pick the one that costs you the least.

    • UX ideas

      Something feels wrong or missing? Open an issue with steps and a screenshot. No design experience needed; friction reports are the most valuable kind.

    • Documentation

      Fix a wrong sentence, or write down something you had to figure out yourself. The docs live next to the code and improve the same way.

    • Translation

      Bring the interface to your language. French and Russian are collected in open feedback threads (français, русский) where rough strings get reported. A new language starts with an issue, so the workflow and the glossary get set up once, properly.

    • Code

      The frontend is plain HTML, CSS, and JavaScript ES modules. No framework, no build step: the code you read is the code that runs. The Rust core and the Android shell sit below it, and the developing guide gets you running in minutes.

    • Donate money or crypto

      The tiers and the current status are in the Support section below. A crypto address will be published here when there is one, and only here.

    Free to use. Optional to fund.

    Velta is GPL-3.0. There is no company, no ads, and no telemetry to pay for the releases. If the app is useful, the work still takes evenings.
