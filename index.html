A cross-platform Delta Chat client

Velta is a private messenger built on the Delta Chat core — end-to-end encrypted, email-based messaging with chatmail relays. No phone number, no tracking.

One web frontend, wrapped by Tauri 2 for Windows, macOS and Android — and running in the browser as a PWA with a WebAssembly core.

Features

Privacy & security

  • End-to-end encryption (Delta Chat / Autocrypt protocol) with guaranteed E2EE for verified chats
  • No phone number — sign up on a chatmail relay in seconds
  • Decentralized: store-and-forward relays, no central server, metadata minimal
  • QR-verified contacts and second devices
  • Join via invite links

Messaging

  • Direct chats, group chats and channels
  • Read receipts, delivery ticks and failed-send indicators with resend
  • Reactions, replies, quoting and forwarding
  • Disappearing (ephemeral) messages
  • Pinned messages with a pin tray
  • Mute per chat, archive folder
  • Photos, videos, files and voice-safe attachments with automatic recompression
  • Stickers
  • Webxdc mini-apps shared right in a chat
  • HTML e-mail viewer
  • Global search with jump-to-message
  • Nicknames, avatars and bot badges

Relays & accounts

  • Multiple accounts in one app
  • Automatic chatmail relay discovery and one-tap adoption
  • Bring your own relay; per-chat relay visibility with live status chips
  • Multi-relay failover with a send-relay pin
  • Connectivity diagnostics with transport-level detail
  • Full self-hosting: the PWA is a static site with the core compiled to WebAssembly, state persisted in the browser across reloads

Platforms & convenience

  • Windows, macOS and Android from one codebase, plus an installable browser PWA
  • System notifications on desktop and Android
  • In-app auto-updates (Windows installer updater, Android APK update)
  • Identity backup and restore between devices
  • Full account export as a downloadable archive
  • Dark theme, adjustable UI scale, send-on-Enter option, keyboard shortcuts

Downloads

  • Windows — x64 installer
