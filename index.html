Private messages.

Velta is a Delta Chat client: encrypted chat, with no company in the middle. Messages travel through chatmail relays you choose, or go straight across with Velta Beam. One interface on Android, Windows, macOS, and in the browser. No analytics.

The ring and the chord.

Velta does not run a messaging server and does not sell the directory. You bring a chatmail address, and the app is the client. Chat rides the ring. Files take the chord.

The ring

Every message

Carries
Every chat message, as encrypted mail through chatmail relays you choose.
Who can read it
No one in the middle. The relay sees timing and size — never the words.
When a relay drops
Another relay on the profile takes over. Failover is built in.
Spam
None. Plain email is dropped on arrival.

The chord

Every file

Carries
Files, peer to peer. Beam goes device to device; Loop runs on the local network.
Who can read it
No one — there is no relay in between and no copy on a server.
Progress
A line per receiver, until every checksum matches.
Beta limits
Loop: up to five devices, 256 MB in a pair, 32 MB in a group.

What a chat gives you.

Velta is a client on the Delta Chat core — the code the protocol comes from. Some of what follows is the core’s doing; some Velta built on top. The tags say which.

01

Encrypted end to end

core

OpenPGP, handled by the core. Velta has no master key and does not keep yours.

02

Reactions, threads, mentions

Velta

React to any message, reply in threads with reply counts, and @mention someone in a way that cuts through mutes. Built in the client, on top of the core.

03

The everyday tools

core + Velta

Full-history search, pins that sync, edits to your own text, stickers, read ticks, and Send later for the exact minute a message should land.

04

Apps in a message

core

Small web apps run inside the chat as a card, drawn in a sandboxed frame that does not share the app’s origin.

What Velta adds.

Velta originals

01

Velta Beam

no relay in between

A file goes peer to peer to the people in the chat; you see each receiver until the checksum matches.

02

Large files

up to 1 GB · key stays in the link

On desktop, the attach menu encrypts a file on your device and uploads it to a Lufi or Cryptex server. The key rides in the link’s # part — the server never sees it — and recipients without Velta download it in any browser.

03

Velta Loop

beta · five devices

A serverless local room on the same network, over iroh QUIC. Text queues while a peer is offline and flushes on reconnect.

04

Velta Prism

one color per person

Every person gets their own color, everywhere: chats, groups, calls. Recognize who is who without photos.

05

Velta Circle

six on a call

Group audio calls, posted as a card in the encrypted chat so nothing rings. Audio flows between participants and the relay’s TURN servers only — nobody sees your IP address.

Built with the core

06

Relays you pick

failover included

More than one chatmail relay on a profile; one is primary, another takes over when it drops. Signup can autopick the fastest relay. Signed invites bring someone in through /join.

07

Audio and video calls

beta · one to one

One to one, beta, end-to-end encrypted like everything else. A call rings only while the app is open; a backgrounded app shows it as missed. Groups call with Velta Circle.

08

Locked when you walk away

encrypted at rest

The database and attachments are encrypted at rest, a capability Velta added to the core itself. A PIN or your fingerprint locks the app; identity backups stay end-to-end encrypted.

09

Quiet by default

trackers stripped

Disappearing messages, tracking parameters stripped from links, HTML mail drawn in a sandboxed frame.

10

Profiles you can leave with

export any time

Add, export, transfer, delete — a second device joins with one QR scan. The same address chats with anyone on the official Delta Chat apps, and moves in or out of Velta at any time.

Nothing phones home.

The promises below are properties of the build, not a policy you have to trust a dashboard to enforce. The source is public, and the frontend ships as plain ES modules: no build pipeline between what you read and what your browser runs.

View the source

01

No telemetry

No analytics, no crash reports, no account of yours on a Velta server — and no update check either.

02

Your mailbox, not ours

Chatmail relays hold ciphertext. Velta does not operate them and cannot read the mail.

03

The app loads itself

A strict content security policy. Pages inside a message do not share the app’s origin.

04

Nothing loads from strangers

Attachments and link previews from unaccepted contact requests wait for your tap — the default on every install, not a setting to find. Tracking parameters are stripped from links.

05

Proxy is opt-in

Android can route mail through a SOCKS5 proxy on a blocked network. It stays off until you enable it.

06

You can leave

Export the profile. Delete it. The license is GPL-3.0, so the client can be forked.

This website measures its own visits cookielessly, in aggregate. The app has no telemetry and never phones home.

Inside the build.

For the people who ask how it holds together — the engineering facts.

01

One contract

the same in every shell

The UI talks to the core over JSON-RPC — the same contract on Windows, macOS, Android, and in the browser build. No shell has its own private API.

02

A carried core

2.69.0 · 200 patches

The Delta Chat core ships vendored and carried: 200 quilt patches across 37 files add relay controls, admin groups, encryption at rest, reply threads, and stall fixes — applied and verified on every build. What each patch does.

03

Speed under load

freezes < 50 ms

Incoming messages batch per frame, notification and chat-list work coalesces, gestures share one delegated listener. On a busy account the longest UI freeze went from about 600 ms to under 50 ms.

04

Built for chat switching

media: immutable

Rendered rows survive chat switches, off-screen media releases its decoder, and media is served immutable — the same blob name always means the same bytes.

Get Velta.

The same frontend everywhere: Android, Windows, macOS, and Linux wrap it with Tauri; the browser runs it on a WebAssembly core. You are not learning a different app on each desk.

    How can you help Velta

    No company is behind this app, so every kind of help is the good kind. Pick the one that costs you the least.

    • UX ideas

      Something feels wrong or missing? Open an issue with steps and a screenshot. No design experience needed; friction reports are the most valuable kind.

    • Documentation

      Fix a wrong sentence, or write down something you had to figure out yourself. The docs live next to the code and improve the same way.

    • Translation

      Bring the interface to your language. French and Russian ship complete; the open threads (français, русский) collect rough strings. A new language starts with an issue, so the workflow and the glossary get set up once, properly.

    • Code

      The frontend is plain HTML, CSS, and JavaScript ES modules. No framework, no build step: the code you read is the code that runs. The Rust core and the Android shell sit below it, and the developing guide gets you running in minutes.

    • Donate money or crypto

      The tiers and the current status are in the Support section below. A crypto address will be published here when there is one, and only here.

    Free to use. Optional to fund.

    Velta is GPL-3.0. There is no company, no ads, and no telemetry to pay for the releases. If the app is useful, the work still takes evenings.
