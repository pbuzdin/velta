# Velta PWA (prebuilt)

Upload these files to an HTTPS host. Do not upload the `.git` directory.

Clone:

```sh
git clone --depth 1 --branch pwa-dist --single-branch \
  https://github.com/pbuzdin/velta.git velta-pwa
```

Guide: https://github.com/pbuzdin/velta/blob/master/docs/pwa-self-host.md

This branch is a snapshot and is force-pushed when the dist is rebuilt.
Source lives on `master`.
